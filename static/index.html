DescTrack

Mux audio description tracks into videos, with an accessible sync mixer. Process one file or a whole batch.

Video / AD audio pairs

Add one pair per video you want to process. Each pair is auto-synced automatically as soon as both files are chosen - the sync mixer is only there if you need to check or fine-tune a particular pair by ear. The Chromecast setting and Start button below apply to the whole batch at once.

Output

Applies to every pair in the batch. When checked, each output is re-encoded to H.264 video in an MP4 container for broadcasting to a Chromecast device. When unchecked, each original video's format and codec are preserved and only the audio track is replaced.

Sync mixer

Tab to the offset control below, then use the Left/Right (or Up/Down) arrow keys to nudge it; keep a key held to nudge in progressively wider increments. Press Enter to lock in the offset. Press Escape at any time to close this dialog.
