A security and efficiency update. Everyone using DescTrack 1.2 should update.

### Security
- Websites you visit can no longer control DescTrack while it is open. Before, any web page could start renders, overwrite "-AD" files next to your videos, or open your file manager.
- ffmpeg may now only open the file formats DescTrack supports, and only local files, so booby-trapped video files can't reach rarely used, vulnerable parts of ffmpeg (such as CVE-2026-64830).
- DescTrack warns you if your ffmpeg is older than 9.0.1, which has known security bugs.
- Updated and removed bundled libraries with known advisories (Werkzeug CVE-2026-102598, OpenSSL 3.5.7, urllib3, certifi).
- Partial files from failed or cancelled renders are cleaned up, and preview clips are kept privately and deleted on exit.

### Faster
- Finding where the sound starts (for previews) is about 20 times faster on HD video.
- Auto-sync and preview clips are about twice as fast.

### Downloads
- Windows: `DescTrack-windows.zip` (unzip, put ffmpeg.exe and ffprobe.exe next to DescTrack.exe)
- Mac (Apple silicon): `DescTrack-mac.zip`
- Linux: `DescTrack-linux-x86_64.tar.gz`

DescTrack needs ffmpeg 9.0.1 or newer; see the README for how to install it.
